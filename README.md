## 화면 테마

- 첫 방문은 시스템의 밝은 모드 또는 어두운 모드를 따른다.
- 오른쪽 위의 시스템, 기본, 블랙 버튼으로 변경한다.
- 수동 선택은 이 브라우저에 저장되며 다른 글과 다음 방문에도 적용된다.
- 시스템을 다시 선택하면 수동 지정을 해제한다.
- 저장소 사용이 차단돼도 현재 페이지에서 테마를 바꿀 수 있다.
- JavaScript를 사용할 수 없을 때는 시스템 설정에 맞는 색상을 적용한다.

## 사이드 메뉴 폴더

- 직접 접거나 펼친 상태를 브라우저에 저장하고 페이지 이동과 재방문 시 복원한다.
- 현재 글이 있는 폴더는 페이지 진입과 뒤로 가기 복원 시 자동으로 펼친다.
- 자동 펼침은 사용자의 저장된 선택을 덮어쓰지 않는다. 다른 폴더는 저장 상태를 유지한다.
- 읽는 중에는 현재 글의 폴더도 직접 접을 수 있으며, 다시 그 글로 진입하면 펼친다.
- 저장이 차단돼도 기본 접기와 펼치기는 동작한다.

전체 동작 검사: `node --test tests/*.test.cjs`
